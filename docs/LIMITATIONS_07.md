# v0.7 exact boundaries

This is an implementation and local-software-verification release, not a claim
that every framework or service has been validated.

* Environment management executes native venv/uv/conda/container commands. Real
  offline venv/uv paths are exercised; conda/Docker/Apptainer require available
  tools and appropriate package sources. It does not solve arbitrary CUDA ABI
  constraints. Observed package health is not native-model success.
* Native stack packs preserve the original finite APIs and custom-repo escape
  hatch. They are not automatic adapters for all MM/Detectron2/SAM variants.
* Guided approval binds source/spec/file inputs. Directory and opaque inputs
  remain incomplete without versioned data manifests. Subprocesses are not
  hostile-code sandboxes and do not preserve cross-process autograd.
* Rich HBB/OBB/mask/grounded payload round trips have software evidence. Actual
  FiftyOne/Supervision SDK execution remains a separate unrun integration here.
  Semantic arrays need explicit decoders; no universal tensor inference exists.
* Methodology lint inspects declared evidence, not scientific truth. Vocabulary
  prompts and shared synthetic meshes are context-dependent, not automatic
  accusations. Evidence references are not independently authenticated facts.
* Static views are read-only exports. HTML/metadata integrity is not a published
  result, model compatibility or independent reproduction. No hosted registry.
* Build/publish/attest/security/DOI tooling requires real owner approvals, account
  setup and permissions. None of those remote operations is claimed executed.
  Final identity, license and namespace remain owner decisions.
* Action pins, recipes and API integrations are source-checked finite choices,
  not a promise of compatibility with future versions. Recipe counts are not
  scientific reproductions. Historical evidence stays labeled historical.
* Ruff/mypy/MkDocs and actual GitHub Actions were unavailable unless explicitly
  stated otherwise in the final report. No unseen check is marked passed.
* GPUs, pretrained external checkpoints, real aerial datasets and independent
  experiments remain external gates. They can expose genuine integration bugs.

There is no new completion percentage: item coverage, local software evidence,
external integration and publication approval are distinct.

Browser execution evidence is in-memory Chromium only. Actual file/HTTP navigation was blocked by platform policy; CSP and hosting behavior were not validated.
