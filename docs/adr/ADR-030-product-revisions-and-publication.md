# ADR-030 — Product workflows preserve ownership and evidence boundaries

Status: accepted for v0.7 alpha

Environment repair creates final-prefix revisions, with metadata health before
an atomic current-pointer update. Old prefixes stay intact. Network and package
installation are part of a digest-bound plan. Dependency presence must never
become a native-model compatibility badge.

Paper inspection is static. Approval is a separate immutable handoff referencing
an unchanged original and an explicitly approved derivative. It is not an
identity certificate or sandbox. Rich native geometry is round-trip audited;
unknown mappings and lossy mask resizing are rejected.

The static browser preserves task/evidence status and displays original
executions separately from reproductions. Legacy and v2 registries are read
without invoking their mutating constructors. UI visualization is not evidence
that the research is correct.

Release build, attestation and publication are separate privilege domains.
Publishing jobs never run repository build scripts. Owner-controlled external
trust mappings and protected environments are prerequisites. Repository security
changes need an exact reviewed plan and readback; local code preparation never
claims those account changes have occurred.
