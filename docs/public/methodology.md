# Inspect methodology without inventing a scientific verdict

```bash
cvrs research lint methodology.json --out review
```

Ruleset 2.0 produces machine-readable findings, severity, evidence, coverage and
remediation. Missing fields yield missing coverage, not a green scientific badge.

The review separates declared/planned budgets from observations carrying evidence
references. Additional synthetic samples and optimizer updates are not the same
intervention. It identifies unequal real exposure, missing controls, omitted
seeds, changed evaluation protocols and floating asset revisions.

Using a predeclared class vocabulary is legitimate in many zero-shot protocols;
it is not automatically label leakage. Per-image ground-truth categories, boxes
or masks create oracle assistance and must remain in an explicitly declared task
track. Prompt assistance is not necessarily misconduct, but it changes the
comparison.

Shared real parent frames/scenes/photogrammetry may violate split policy. Reusing
a mesh may be legitimate or prohibited depending on the generalization question.
The policy therefore names lineage kinds that must not cross; the reviewer does
not decide universal contamination rules from asset names alone.

A warning is not a causal finding. A structurally consistent experiment can still
have bad labels, unsuitable data or an unsupported conclusion. This software
helps make declared decisions inspectable.
