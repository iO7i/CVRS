# Slice 6 limits and review boundaries

## Implemented software is not native-model certification

The version extends the previous source; it does not replace it with a scaffold. Whole native models stay in their native environment. The composition runner exchanges materialized, typed files. It cannot transparently partition a joint-autograd network, adapt arbitrary feature geometry, or remove internal dependency conflicts.

## Optional native integrations

MMRotate/MMYOLO/MMSeg/MMDeploy/Detectron2/SAM3, native pretrained models, external SDKs and authentic paper assets were not installed or run here. Their code calls actual native APIs, but pinned versions may require further integration corrections. Environment packs with missing pins are INCOMPLETE, never certified installations. Paper recipes are attributed preparation records with missing revisions/assets kept explicit.

FiftyOne and Supervision have HBB-specific bridges; native mask/OBB coverage is not implied. MMSeg semantic maps stay distinct from instance masks. TerraTorch fit/predict uses its native output; task-specific decoding must be declared. OpenML support is task/run metadata, not arbitrary CV submission equivalence. Code Ocean output is a preparation tree, not a remotely created or verified capsule. Simulator imports are finite export readers/maps, not live simulator control.

## Evidence and methodology

Procedural fixture labels and randomly initialized detectors prove transport, geometry, bookkeeping and execution only. A same-machine rerun is not independent reproduction. Methodology rules inspect supplied metadata; they cannot prove causality or detect all data contamination. Static API compatibility checks flag structural changes, not semantic equivalence.

## Scope of isolation and permissions

Workers run trusted executable native code. Dependency separation and network guards are not security sandboxes. Reviewed argv avoids shell interpolation but does not make the invoked program harmless. File input hashes are verified; directory/opaque dependency closure remains explicitly partial. Archives and logs are allowlisted/redacted, not guaranteed free of every unknown secret format. Remote transfers, downloads and copied images require explicit consent.

## Publication

The identity, final repository URL, copyright owner, authors and source-license grant remain owner decisions. Clean public-source output is provided only as OWNER_PREVIEW. It must not be described as approved open-source distribution until those decisions are applied and the audit reviewed. No remote repository, PyPI publication, cloud resource, account or paid job was created.

Ruff, mypy, native MkDocs, Docker builds, GitHub Actions, GPU/cluster execution and external service SDK operation were not executed here. Ruff/mypy installation was attempted and unavailable. Offline built-in docs and software/CPU workflows have separate executed evidence.
