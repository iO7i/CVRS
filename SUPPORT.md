# Support

Start with `cvrs doctor --python NATIVE_PYTHON`, the exact command, package/worker versions and the structured error code. Installed does not mean compatible.

Use `cvrs support bundle RUN --out NEW_DIRECTORY` for a sanitized metadata bundle. Review it before uploading. Do not attach datasets, credentials, private checkpoints or source history by default.

For native import failures report the pinned framework revision and environment recipe. For metric disagreement include evaluator identity, taxonomy/coordinate policy and prediction hashes. For a failed reproduction include claim/capsule identity and attempt evidence.

There is no promised service-level agreement or commercial support channel. The owner must configure actual public issue and private security routes before launch.
