# Third-party relationships and notices

CVRS calls optional native packages through their public APIs or reviewed local entrypoints. It does not claim OpenMMLab, Detectron2, Meta, Hugging Face, NVIDIA, Roboflow, Voxel51, W&B, MLflow, DVC, Code Ocean, OpenML, TorchGeo or TerraTorch affiliation.

Original code licensing remains an owner decision. Keep upstream notices when redistributing any copied source. Optional runtime libraries, model weights, configs, datasets and generated assets may have different licenses; a Python package license does not determine checkpoint/data rights.

The public builder excludes weights and dataset archives by default. `licenses report`, asset acknowledgements and the build-environment SBOM are evidence/metadata tools, not legal determinations. Review the actual license grant before redistribution.
