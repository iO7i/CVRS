# Roadmap

## Now

Finish owner-reviewed release metadata and execute provisional integrations in pinned native environments. Preserve failures and compare against the original task protocol.

## Next

Improve real-user onboarding based on reproducible issue reports. Add narrowly justified adapters and paper recipes only when they reduce work without changing native methodology.

## Later

Additional task families and infrastructure remain independent extensions, not hidden conditions for publishing this local-first project.

## Non-goals

A universal model zoo, cloud scheduler, annotation platform, hosted MLOps replacement, arbitrary model graph rewriting, live simulator control or claims that every 2026 research paper is reproduced.

Implementation, execution, verification and scientific reproduction are separate status dimensions.
